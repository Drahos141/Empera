Q: How to add more fantasy 2D pixel art?
──────────────────────────────────────────────────────────
The game currently draws all art procedurally using Canvas 2D API
(no image files). Here are your options:

OPTION A – Keep the procedural approach (current style):
  • All unit, building and tile visuals are drawn in drawUnitSprite(),
    drawBuilding(), and drawTile() functions in game.js
  • To add new art, create a new case in the switch() block and
    draw shapes using ctx.fillRect, ctx.arc, ctx.beginPath etc.
  • This approach is lightweight and always crisp at any resolution

OPTION B – Use real pixel art PNG sprites:
  1. Create 48x48 (or 96x96 for @2x) PNG sprite sheets using:
     • Aseprite (best pixel art tool, ~$20, worth every cent)
     • LibreSprite (free, open source fork of Aseprite)
     • Pixilart.com (free browser tool)
     • Lospec.com/palette-list (for palette inspiration)
  2. Load images in JS:
       const img = new Image();
       img.src = 'sprites/units.png';
       img.onload = () => { /* game is ready */ };
  3. In drawUnitSprite(), replace canvas drawing with:
       ctx.drawImage(img, srcX, srcY, 48, 48, dx, dy, 48, 48);
  4. Organize as a sprite sheet (all units on one PNG, units
     in rows, animation frames in columns)

OPTION C – Free fantasy pixel art resources:
  • OpenGameArt.org – search "fantasy RTS" or "warcraft style"
  • itch.io – search "pixel art fantasy game assets"
  • Kenney.nl/assets – free game assets (not pixel art but clean)
  • CraftPix.net – paid but affordable fantasy packs

OPTION D – AI-generated pixel art:
  • Midjourney with prompt: "pixel art fantasy warrior, 48x48, top down view"
  • Leonardo.ai (free tier available): good for sprite sheets
  • DALL-E 3: "16-bit pixel art [unit type], transparent background"

Can I (the AI) create pixel art for you?
  Unfortunately I cannot generate image files directly. I can only
  create code that DRAWS shapes procedurally on the canvas.
  For actual PNG pixel art files, use the tools listed above.
  The existing procedural sprites in game.js are a good starting
  point – they look stylized and match the game's aesthetic.
