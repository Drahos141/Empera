⚔️ How to Play EMPERA

Controls

  • Left-click – select unit / building
  • Left-drag – box-select multiple units
  • Right-click – move / gather / attack
  • Arrow keys – scroll map
  • Mouse edge – auto-scroll map
  • A – select all visible player units
  • H – center on Main Hall
  • P – set patrol (press twice: A→B)
  • Esc – deselect / cancel build

Gathering

  • Select workers, right-click a gold mine (yellow) to gather gold
  • Select workers, right-click a tree (dark green) to chop wood
  • Workers automatically return to Main Hall and go back

Buildings

  • Select a worker → Build panel appears on right
  • Click a building button, then click on the map to place
  • Send workers to a construction site to build it
  • Farm – +5 population cap
  • Barracks – train Footman & Archer
  • Blacksmith – train Knight
  • Mage Tower – train Mage
  • Stable – train Cavalry
  • Siege Workshop – train Catapult
  • Temple – train Priest (healer)
  • Tavern – train Hero (gains XP & levels!)
  • Watch Tower – auto-attacks enemies
